# Modular Python Calculator & Utility Package

> **A custom Python package implementing mathematical and calculator utility functions with modular import structures.**

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python&logoColor=white)](https://python.org)

---

## 1. Overview

Demonstrates modular Python software architecture, reusable utility creation, and package importing:
- `calc_function.py`: Core mathematical library with arithmetic, power, and algebraic helpers.
- `custom module.ipynb`: Interactive test suite importing `calc_function` and verifying function outputs.
